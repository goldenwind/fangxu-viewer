# 方序看图 (Fangxu Viewer)

一款极速、轻量、跨平台（Windows + macOS）的简约看图软件，界面布局与操作习惯深度参考经典的 **2345 看图王**。基于 Tauri 2 + Rust + 原生 JavaScript 构建。

---

## 产品特性

- **2345 经典看图体验**：
  - 沉浸式暗黑底色 (`#18181b`) 与透明图棋盘格背景；
  - 经典半透明毛玻璃悬浮底部控制药丸栏（支持自动淡化与升降适配）；
  - 左右两侧边缘动态半透明大翻页箭头（鼠标悬停浮现）；
  - 鼠标滚轮以光标所在点为中心平滑缩放，按住左键自由拖拽平移；
  - 鼠标双击智能切换“适应窗口”与“1:1 实际大小”。
- **多格式全能支持**：
  - 支持 JPG、JPEG、PNG、GIF、WebP、BMP、SVG、ICO、TIFF、TIF、AVIF、HEIC 等主流图片格式；
  - 支持多帧动图与透明通道无损查看。
- **极速同级目录浏览**：
  - 打开任意图片，自动高效扫描同目录全部图片；
  - 采用**自然数文件名排序 (Natural Sort)**，精准还原 `img1, img2, img10` 逻辑顺序。
- **底部缩略图胶片条 (Filmstrip)**：
  - 按 `T` 或点击底部胶片图标展开/收起底部缩略图导航栏；
  - 缩略图横向滑动，自动居中当前高亮图片，点击快速跳转。
- **图片属性与 EXIF 详情**：
  - 按 `I` 呼出侧边抽屉，直观查看尺寸、分辨率 (MP)、色彩空间、文件大小、修改时间；
  - 支持数码相机/手机拍摄参数：光圈、快门、ISO、焦距、曝光补偿、闪光灯、相机与镜头型号。
- **全屏放映与幻灯片 (Slideshow)**：
  - 按 `F11` 或 `Enter` 一键全屏；
  - 按 `F5` 开启全屏幻灯片放映，提供悬浮 mini 播控条（播放/暂停、多档间隔调节 1.5s/3s/5s/8s）。
- **个性化偏好设置（使用习惯自定义）**：
  - 按 `Ctrl/Cmd + ,` 或点击右上角“设置”图标呼出偏好设置面板；
  - **鼠标滚轮习惯**：支持“以光标为中心实时无级缩放”与“向上/向下滚动翻页浏览”一键切换；
  - **翻页循环穿透**：可配置首末张循环穿透（末张继续翻回到首张）或触底停止；
  - **底部缩略图胶片栏**：可设置启动打开图片时是否默认显示缩略图胶片条；
  - **双击交互**：可自选双击“适应窗口与 1:1 实际尺寸切换”或双击“进入/退出全屏”；
  - **视口背景风格**：支持沉浸深灰、透明棋盘格、纯黑背景、极简浅灰四种主题风格；
  - **放映速度**：自定义幻灯片轮播间隔（1.5s / 3s / 5s / 8s）。
- **纯粹本地离线**：
  - 完全移除了登录、会员购买等干扰模块，打造极简、纯粹、安全的本地开箱即用看图神器。

## 快捷键一览（参考 2345 看图）

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`←` / `PageUp` / `A`** | 上一张图片 |
| **`→` / `PageDown` / `D`** | 下一张图片 |
| **`Home` / `End`** | 跳转到当前目录第一张 / 最后一张图片 |
| **`空格 (Space)`** | 下一张图片 / 幻灯片播放时暂停与继续 |
| **`鼠标滚轮`** | 缩放 或 翻页（可在设置中自选习惯） |
| **`鼠标左键拖拽`** | 放大后平移查看细节 |
| **`鼠标双击`** | 适应窗口与 1:1 切换 / 全屏切换（可在设置中自选习惯） |
| **`↑` / `+` / `=`** | 放大图片 |
| **`↓` / `-`** | 缩小图片 |
| **`1`** | 实际大小 (100% 原始比例) |
| **`0`** | 适应窗口大小 |
| **`L`** | 逆时针旋转 90° |
| **`R`** | 顺时针旋转 90° |
| **`H` / `V`** | 水平镜像翻转 / 垂直翻转 |
| **`F11` / `Enter`** | 进入 / 退出全屏模式 |
| **`F5`** | 开启幻灯片自动放映 |
| **`T`** | 展开 / 折叠底部缩略图胶片栏 |
| **`I`** | 打开 / 关闭图片属性与 EXIF 详情 |
| **`Delete`** | 将当前图片移入系统回收站 |
| **`Ctrl` / `Cmd` + `,`** | 打开偏好设置 |
| **`Ctrl` / `Cmd` + `O`** | 打开本地图片 |
| **`Ctrl` / `Cmd` + `S`** | 图片另存为 |
| **`Ctrl` / `Cmd` + `C`** | 复制图片数据至系统剪贴板 |
| **`Esc`** | 退出全屏 / 关闭弹窗 / 重置缩放 |

## 开发与构建

### 环境要求
- Node.js 20+
- Rust stable (1.80+)
- 操作系统对应 Tauri 2 依赖

### 本地开发
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run tauri dev
```

### 自动化验证与构建
```bash
# 运行单元测试
npm run test

# 构建前端产物
npm run build

# Rust 编译与测试
cargo test --manifest-path src-tauri/Cargo.toml

# 一键运行全部检查
npm run check
```

│       ├── lib.rs               # Tauri 入口与命令注册
