# 方序看图产品反馈

- 产品名称：方序看图
- 产品 ID：`12`
- 产品标识：`fangxu_viewer`
- 反馈地址：<https://api.ip21.cn/products/12/feedback>

“偏好设置”的“关于与更新”中的“提交反馈”，以及菜单栏“帮助”中的“产品反馈...”，在软件内打开独立的原生 WebView 窗口，直接展示上述产品页面。重复点击会恢复并聚焦已有窗口，不刷新页面，保留正在填写的内容。关闭反馈窗口不影响主窗口看图体验；再次打开会重新加载页面。反馈沿用现有公众号登录流程，登录仅用于反馈，看图无需账号。反馈类型统一为功能故障（`bug`）、功能建议（`feature`）、登录与购买（`login_purchase`）、其他反馈（`other`）。

## 软件环境

桌面端点击反馈入口时读取当前软件和系统信息，通过 URL 片段携带四个字段：

| 字段 | 来源 | 最大字符数 |
| --- | --- | --- |
| `app_version` | 当前 Tauri 应用版本（`tauri.conf.json`） | 64 |
| `os` | 原生运行平台：`macos`、`windows`、`linux` | 32 |
| `os_version` | `os_info` 读取的系统版本；读取不到时省略 | 128 |
| `arch` | `os_info` 读取的系统架构；读取不到时使用客户端编译架构 | 32 |

所有值先去除首尾空格并按字符数截断，再按 URL 表单参数编码。例如：

```text
https://api.ip21.cn/products/12/feedback#app_version=0.1.0&os=macos&os_version=15.6.1&arch=arm64
```

反馈页读取后立即清除片段，将环境信息显示在表单中，并在用户提交反馈时原样提交。
原生能力仍只授权给 `main` 窗口，反馈窗口没有文件修改或本地执行的原生权限。
